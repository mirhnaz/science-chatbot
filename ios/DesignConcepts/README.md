# Science Chatbot icon concepts

`rocket-atom-concepts.png` contains the initial three-direction exploration:

1. Rocket crossing a single atomic orbit
2. Rocket formed with atom-inspired geometry
3. Rocket launching from an atomic nucleus

The second direction was selected. `rocket-atom-master.png` is the reusable
full-resolution master for iOS and the web. The production iOS copies live in
the `AppIcon` and `BrandIcon` asset sets.
